# Maria Martin · web de demostración

Web de demostración para un centro de estética avanzada en Murcia: elige tu mirada, test de piel y calculadora del precio por sesión de láser.

**Verla publicada:** https://maria-martin-demo.vercel.app/

## Cómo está hecha
- HTML, CSS y JavaScript sin framework
- GSAP, ScrollTrigger y Lenis
- Datos de tratamientos en datos.js y módulos interactivos en modulos.js
- Alojada en Vercel

## Verla en local
```
python -m http.server 8000
```
y abre http://localhost:8000/

## Sobre esta web
Diseño y desarrollo de [Dania360](https://dania360.com). Es una demo: los textos, las fotos y la marca del negocio pertenecen a sus dueños, y la web no se indexa en buscadores (`noindex`). El código se publica para enseñar cómo está hecha; no tiene licencia de uso.

Más webs en el portafolio: https://dania360-portafolio.vercel.app
